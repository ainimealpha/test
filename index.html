5–20 PEMAIN · 1 NARATOR · 1 PERANGKAT

PANDUAN BERMAIN

🎭 Tim & Peran
⚔️ HERO — Guardian · Visioner · Healer · Archer (punya skill & pasif)
👤 CIVILIAN — Terbanyak. Tanpa skill. Kekuatan di voting.
💣 VILLAIN — Assassin · Thief · Bomber (musuh tersembunyi)
🃏 ANTI-HERO — Trickster · Dummy (menang jika Villain menang)
📱 Alur Permainan
1. Pembagian Peran — HP digilir tiap pemain. Lihat peranmu secara pribadi.
2. Pilih Tim Misi — Diskusi pilih anggota sesuai jumlah pemain.
3. Misi Rahasia — Tiap anggota dapat soal berbeda. Gagal/skip = sabotase!
4. Malam Hari — Karakter gunakan skill lewat HP secara rahasia.
5. Pagi & Voting — Hasil malam diumumkan. Diskusi → eliminasi 1 orang.
🏆 Kondisi Menang
Hero + Civilian → Semua Villain (Assassin+Thief+Bomber) tereliminasi
Villain → Villain ≥ Hero+Civilian hidup, ATAU 3 misi gagal
Anti-Hero → Jika kondisi Villain menang tercapai + Anti-Hero hidup → Anti-Hero menang (override Villain!)
Dummy spesial → Divoting keluar setelah malam ke-2 + min. 5 pemain hidup → Anti-Hero menang!
⚡ HERO — Skill & Pasif
⚔️ Guardian — Lindungi 1 orang dari serangan malam (bukan diri sendiri). Pasif: Jika berhasil melindungi Civ/Hero yang diserang → dapat 1 use lagi (maks 2x).
🔮 Visioner — Lihat role 1 pemain (1x). Pasif: Jika skill belum dipakai + diserang Villain → Villain mati, Visioner selamat. Setelah pasif aktif, skill terkunci.
💚 Healer — Bangkitkan 1 Civ/Hero (mulai malam ke-2). Hero dibangkitkan = jadi Civilian. Pasif: Jika gugur sebelum pakai skill → malam berikutnya bisa bangkitkan 1 orang (Hero = skill saja).
🏹 Archer — Blokir skill 1 pemain selama 1 malam. Pasif: Jika target Villain → dapat 1 use lagi ke target beda (maks 2x).
💀 VILLAIN — Skill & Pasif
🗡️ Assassin — Eliminasi 1 orang di malam hari (1x). Pasif: Jika Hero+Civilian awal ≥9 → dapat 2x skill selama game.
🥷 Thief — Curi skill + pasif 1 pemain (1x, target kehilangan segalanya). Pasif: Jika target Civilian → gagal & hangus. Jika target sudah pakai skill → target ikut mati.
💣 Bomber — Jika Visioner intip Bomber → Visioner yang mati! Pasif: Jika divoting keluar → pilih 1 Civ/Hero untuk ikut gugur.
🃏 ANTI-HERO — Pasif
🃏 Trickster — P1: Dilihat Visioner = tampil sebagai Civilian (1x). P2: Ditarget Assassin = Assassin buang 1 skill use (1x).
🎭 Dummy — P1: Kebal 1x dari semua skill Hero/Villain. P2: Divoting keluar (malam ke-2+, ≥5 hidup) = Anti-Hero menang!
